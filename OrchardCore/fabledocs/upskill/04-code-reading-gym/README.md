# 04 — Code Reading Gym

Reading code is a trained skill: inputs, outputs, invariants, side effects, failure modes — extracted fast and accurately. Four workout types:

| File | Workout | Reps |
| --- | --- | --- |
| [01-annotation-drills.md](01-annotation-drills.md) | Annotate real excerpts | 10 drills |
| [02-trace-tables.md](02-trace-tables.md) | Follow data through layers | 5 tables |
| [03-fake-code-contrasts.md](03-fake-code-contrasts.md) | Bad-vs-better pairs tied to repo patterns | 10 pairs |
| [04-review-katas.md](04-review-katas.md) | Review fake PRs like a mid-level engineer | 8 katas |

Rules: write your answer **before** reading the provided one; grade yourself with the rubric; a drill you aced from memory a week later is the only drill that counts.

These drills feed directly into interview rounds: annotation ≈ "walk me through this code," traces ≈ debugging rounds, katas ≈ code-review rounds ([08-interview-prep/05](../08-interview-prep/05-debugging-and-code-review-rounds.md) reuses several with timers).

## How to use this register

- For **learners**: each row is a debugging or design exercise — turn it into a test (the "Suggested test" column is your ticket).
- For **contributors**: verify before acting; R1/R6 may warrant private disclosure if confirmed. Search existing issues first — some may be known/intended.
- For **interviews**: R1–R4 are your "critique a system" material — deliver each as claim → evidence → impact → fix → cost in ~90 seconds ([08-interview-prep/04](../08-interview-prep/04-system-design-from-this-repo.md)).

# 06 — Contribution Practice

Reading builds understanding; contributing builds judgment. This track is a ladder of realistic work against this repo — usable as actual OSS contributions (check the issue tracker first; coordinate before large changes) or as private practice.

| File | Level | Contents |
| --- | --- | --- |

| [04-refactor-and-design-katas.md](04-refactor-and-design-katas.md) | Senior practice | 8 katas with self-grading |

**Contribution realism rules** (every ticket here answers them): why it's useful; why the blast radius is small; which existing pattern it follows; how it's tested; what would make a maintainer reject it. Before opening a PR: read [CONTRIBUTING.md](../../../CONTRIBUTING.md), search existing issues/PRs, and follow [07-career-and-collaboration/02](../07-career-and-collaboration/02-writing-prs-and-rfcs.md).

Every ticket carries an **Interview story potential** line — completing it hands you a STAR story ([08-interview-prep/06](../08-interview-prep/06-behavioral-star-stories.md)).
